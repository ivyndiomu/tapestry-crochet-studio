# Selected product evolution

This is a portfolio-facing change log, not a complete engineering release log.

## Foundation

- artwork import
- measured gauge input
- gauge-corrected pattern height
- configurable stitch width and colour count
- editable pattern grid
- palette editing
- basic grid tools
- stitch/colour-change statistics
- bottom-up written row instructions
- local autosave and project backup
- PNG / print-PDF path

## Professional workflow expansion

- crop and cleanup controls
- more capable grid editing
- garment panel modelling
- physical panel sizing and placement
- yarn library and matching
- production progress and timing
- professional export direction
- business/customer/order workflow

## Multi-panel evolution

- front/back/sleeve/custom panels inside one project
- panel-specific palette and design state
- duplicate and move design between panels
- project-level production and yarn aggregation
- freestyle panel canvas

## Construction-aware evolution

- armhole and neckline shaping independent of artwork
- sleeve construction direction and decrease planning
- physical stitch counts that exclude cut-out garment cells
- manual edits around the placed design

## Client-preview iteration

In v0.12.10, sleeves were removed from the front and back client-preview views while left and right sleeves remained as separate preview cards. This reduced duplication and made the flat-panel approval model clearer.
