# Research and metrics

## Current research objective

Determine whether experienced makers experience the same workflow fragmentation, can complete the core flow without founder assistance, and return for another project.

## Interview prompts

- Walk me through the last tapestry crochet project you made from an image.
- Which tools or documents did you use from source image to finished item?
- How did you decide stitch and row counts?
- What do you edit manually after generating a chart?
- How do you plan front, back and sleeve designs?
- How do you handle neckline, armhole or seam conflicts?
- How do you decide which yarn colours to buy?
- What mistakes happen while following rows?
- For paid work, how do you quote, collect deposits and secure approval?
- Which repeated step is most frustrating?

## Activation definition

A user creates or opens a project, enters gauge, creates a pattern or freestyle panel, reaches a valid production-ready panel, then starts production or completes an export.

## Metrics to validate

- time to production-ready panel
- manual correction burden per generated pattern
- correction type frequency
- project save success
- migration success
- export success
- repeat project creation within 30 days
- production completion rate
- quote-to-deposit conversion for business users

## What is intentionally not claimed yet

This project does not currently claim:

- product-market fit
- external user growth
- retention
- revenue attributable to the software
- proven time savings
- statistically validated accuracy improvements

Those outcomes require real measurement, not portfolio storytelling.
