# Product overview

## Vision

Make custom tapestry crochet production as structured and controllable as a professional design-to-production workflow while preserving the maker's ability to intervene manually wherever craft judgement matters.

## Problem

A custom tapestry crochet order crosses several systems at once:

- source image preparation
- non-square stitch geometry
- colour reduction
- manual chart correction
- garment dimensions and construction zones
- real yarn availability
- row-by-row instructions
- production progress
- client approval
- quoting, deposits and deadlines

Generic pixel or image tools address only a fraction of this workflow. The maker must reconcile the rest manually.

## Primary user

The initial user is the owner of a custom tapestry crochet business. The next validation group is experienced makers who sell custom tapestry work or regularly create image-based crochet projects.

## Core jobs to be done

When I receive an image for a custom crochet project, help me convert it into a physically accurate, editable pattern that fits the intended panel and can be produced row by row.

When I prepare a paid custom order, help me keep design, materials, approval, production and commercial status connected to the same project.

## Current product areas

- project and persistence
- artwork preparation
- gauge-aware conversion
- palette and manual grid editing
- multi-panel garment design
- construction-aware pattern logic
- crochet intelligence and written instructions
- yarn intelligence
- production mode
- professional exports
- client preview
- business workflow
- desktop packaging direction

## Non-goals for the current validation stage

- a general accounting platform
- a social network for makers
- a marketplace
- broad collaboration features before individual workflow validation
- cloud-first architecture before local production reliability
