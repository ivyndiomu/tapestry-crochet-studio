# Roadmap

## Historical product phases

The product was originally structured as a phased progression:

0. Foundation and versioned project model
1. Manual grid editor
2. Image-to-grid MVP
3. Crochet-aware conversion
4. Professional editing
5. Crochet intelligence
6. Garment designer
7. Yarn intelligence
8. Production mode
9. Professional exports
10. Business workflow
11. Premium automation
12. Desktop packaging
13. Cloud / SaaS

The sequence matters. Cloud accounts, subscriptions and team collaboration were deliberately positioned after the core production workflow.

## Now

### Reliable desktop production workflow

- use real orders end to end
- resolve export and preview defects
- validate garment and construction logic
- reduce workflow dead ends
- verify project save and migration behaviour
- improve onboarding for a first complete project

## Next

### Design-partner validation

Recruit a small group of experienced makers and measure:

- independent activation
- time to production-ready panel
- correction burden
- export success
- repeat project creation
- failure points that force users back to other tools

## Later

### Cloud and commercial service

Only after the single-user workflow earns it:

- accounts
- encrypted sync
- subscriptions
- team/shared libraries
- client approval links
- analytics
- multi-device continuity

## Roadmap rule

A feature moves forward when it reduces a validated workflow problem, protects production correctness or enables a measurable commercial/operational outcome. Novelty alone is not sufficient.
